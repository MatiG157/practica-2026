# Practico 07 - Capa de Presentacion

Implementacion en Flask para gestionar socios utilizando la capa de negocio del practico 06.

## Funcionalidades

- Listado de socios en tabla principal.
- Alta de socios con formulario y botones Guardar / Cancelar.
- Baja de socio desde la tabla principal.
- Modificacion de socio con formulario y botones Aceptar / Cancelar.

## Ejecucion

1. Instalar Flask:

   pip install flask

2. Desde la raiz del repositorio, ejecutar:

   python practico_07/app.py

3. Abrir en navegador:

   http://127.0.0.1:5000/
